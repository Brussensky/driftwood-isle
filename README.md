# Driftwood Isle: audio demo

A playable audio demo for a cozy island merge game. Sound design, music and mix by Alexey Nagrani (soundsbetter.ru).

- `index.html` – the page: mock game, sound list and design notes, plain HTML/CSS/JS with the Web Audio API
- `audio/` – 16-bit / 48 kHz WAV files used by the page

Original concept for portfolio purposes, not affiliated with any studio.
